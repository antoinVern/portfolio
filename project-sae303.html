Périmètre du projet

Ce projet de fin de semestre simule une migration réelle vers une infrastructure professionnelle. L'objectif : concevoir et déployer une infrastructure réseau moderne et redondante pour une PME, garantissant la haute disponibilité des services et une sécurité renforcée des accès.

Pôle 1

Services d'Annuaire et Identité — Active Directory

Le cœur de l'infrastructure identitaire repose sur un domaine etu40.sae géré via AD-DS sur Windows Server 2022. La structuration en unités d'organisation (OU) permet une administration granulaire des utilisateurs par métier.

1
Déploiement du domaine etu40.sae
Installation du rôle AD-DS et promotion du serveur en contrôleur de domaine. Création du domaine etu40.sae. Configuration du DNS intégré à l'Active Directory.
# PowerShell — Installation AD-DS et promotion DC Install-WindowsFeature -Name AD-Domain-Services -IncludeManagementTools Install-ADDSForest ` -DomainName "etu40.sae" ` -DomainNetbiosName "ETU40" ` -InstallDNS ` -Force
Domaine etu40.sae opérationnel
2
Structuration en unités d'organisation (OU)
Création d'une hiérarchie d'OU segmentée par métier pour appliquer des GPO ciblées et gérer les accès avec précision. Chaque OU dispose de groupes de sécurité dédiés.
Arborescence OU déployée :
  • OU=Production — opérateurs machines, accès restreint
  • OU=Techniciens — personnel technique, droits étendus
  • OU=Responsables — management, accès complet aux ressources
3 OU + groupes de sécurité déployés
3
Haute disponibilité — Contrôleur de domaine redondant
Configuration d'un second contrôleur de domaine avec réplication Active Directory. En cas de panne du DC principal, le secondaire prend automatiquement le relais, garantissant la continuité d'authentification.
# Vérifier l'état de la réplication AD repadmin /replsummary repadmin /showrepl # Forcer une réplication immédiate repadmin /syncall /AdeP
Réplication AD validée — infrastructure redondante

Pôle 2

Infrastructure Réseau et Mobilité

L'architecture LAN s'appuie sur des switchs Cisco 2960 interconnectés via un routage dynamique OSPF. La partie Wi-Fi intègre une sécurité enterprise en liant l'authentification physique à l'annuaire Active Directory.

1
Routage dynamique OSPF
Configuration du protocole OSPF (Open Shortest Path First) sur les routeurs pour un routage dynamique et adaptatif. Les routes sont annoncées automatiquement entre les équipements du réseau.
! Configuration OSPF sur routeur Cisco router ospf 1 router-id 1.1.1.1 network 192.168.10.0 0.0.0.255 area 0 network 192.168.20.0 0.0.0.255 area 0 passive-interface default no passive-interface GigabitEthernet0/0
Routage dynamique OSPF opérationnel
2
Wi-Fi WPA2/WPA3 Enterprise — Authentification RADIUS (NPS)
Implémentation d'une authentification 802.1x / WPA2-WPA3 Enterprise via le serveur NPS (Network Policy Server) intégré à Windows Server. Les utilisateurs s'authentifient directement avec leurs comptes Active Directory pour se connecter au Wi-Fi.
Flux d'authentification :
  • Poste client → Point d'accès (demande EAP)
  • Point d'accès → Serveur RADIUS/NPS (RADIUS Access-Request)
  • NPS → Active Directory (vérification des identifiants)
  • Réponse : RADIUS Access-Accept ou Access-Reject
Authentification Wi-Fi couplée à l'AD — 802.1x validé
3
SSID Invités — Réseau isolé
Création d'un SSID "Invités" dédié, diffusé uniquement sur la bande 2,4 GHz avec une limitation de débit. Ce réseau est totalement isolé du LAN interne — aucun accès aux serveurs, partages ou ressources de l'entreprise.
Segmentation invités validée — zéro accès aux ressources internes

Pôle 3

Services Réseau Avancés

En complément de l'infrastructure de base, plusieurs services métiers ont été déployés pour répondre aux besoins opérationnels de la PME : accès distants sécurisés, hébergement d'intranet et distribution d'adresses IP.

1
DHCP centralisé sur routeur
Déploiement du service DHCP directement sur le routeur Cisco pour une gestion centralisée des baux IP. Un pool par segment réseau, avec exclusion des adresses réservées aux équipements fixes (serveurs, imprimantes).
! Pool DHCP sur routeur ip dhcp excluded-address 192.168.10.1 192.168.10.20 ip dhcp pool VLAN-STAFF network 192.168.10.0 255.255.255.0 default-router 192.168.10.1 dns-server 192.168.10.5 lease 7
Distribution IP automatique opérationnelle
2
Remote Desktop Web (RD Web)
Mise en place d'un portail Remote Desktop Web permettant aux collaborateurs d'accéder à leurs applications métiers (LibreOffice, outils internes) depuis n'importe quel navigateur, sans client RDP installé. L'authentification se fait via les comptes Active Directory.
Accès distant sécurisé via navigateur — authentification AD
3
Serveur web intranet — Apache sur Debian 10
Déploiement d'un serveur web Apache sous Debian 10 pour l'hébergement de l'intranet d'entreprise. Accessibles uniquement depuis le réseau interne, les pages fournissent les ressources et informations nécessaires aux collaborateurs.
# Installation Apache sur Debian 10 apt update && apt install -y apache2 # Activation et démarrage du service systemctl enable apache2 systemctl start apache2 # Vérification du statut systemctl status apache2
Intranet Apache en ligne — accès interne uniquement

Pôle 4

Automatisation et Supervision — Observabilité

La gestion manuelle d'une infrastructure d'entreprise est un facteur de risque. Ce pôle couvre la supervision proactive des serveurs et l'automatisation de la configuration et de l'administration du parc.

1
GPO — Group Policy Objects
Déploiement de stratégies de groupe (GPO) ciblées par OU pour automatiser la personnalisation et la sécurisation des postes clients.
GPO déployées :
  • Fond d'écran par métier — identité visuelle automatique selon l'OU de l'utilisateur
  • Blocage CMD — désactivation de l'invite de commande pour les profils Production
  • Déploiement de raccourcis web — icônes sur le bureau pour l'intranet et les outils métiers
3 GPO déployées et appliquées
2
Monitoring — Stack Prometheus + Grafana
Installation de la stack d'observabilité Prometheus + Grafana couplée au Windows Exporter sur chaque serveur Windows. Les métriques sont collectées en temps réel et affichées dans des tableaux de bord personnalisés.
Métriques supervisées :
  • CPU — charge processeur par serveur
  • RAM — utilisation mémoire et disponibilité
  • Trafic réseau — entrées/sorties par interface
  • Services Windows — état en temps réel (AD, NPS, DHCP…)
Tableaux de bord Grafana opérationnels en temps réel
3
Script PowerShell — Audit et export des utilisateurs AD
Développement d'un script PowerShell d'audit permettant d'exporter l'ensemble des utilisateurs Active Directory (avec leurs attributs) vers un fichier CSV. Utilisé pour les audits de conformité et les rapports de gestion.
# Export des utilisateurs AD vers CSV Get-ADUser -Filter * -Properties * | ` Select-Object Name, SamAccountName, EmailAddress, ` Department, Title, Enabled, LastLogonDate | ` Export-Csv -Path "C:\Audit\users_export.csv" ` -NoTypeInformation -Encoding UTF8 Write-Host "Export terminé — $((Import-Csv 'C:\Audit\users_export.csv').Count) utilisateurs exportés."
Script d'audit AD opérationnel — export CSV automatisé

Compétences validées

Ce projet couvre l'intégralité de la chaîne d'une infrastructure PME professionnelle, de l'annuaire jusqu'à la supervision, en passant par la sécurité des accès filaires et sans fil.

  • Administration Windows Server 2022 : AD-DS, NPS, RD Web, GPO
  • Haute disponibilité : réplication Active Directory multi-contrôleurs
  • Sécurité Wi-Fi enterprise : 802.1x / RADIUS couplé à l'AD
  • Routage dynamique OSPF sur infrastructure Cisco 2960
  • Supervision proactive : stack Prometheus + Grafana + Windows Exporter
  • Automatisation PowerShell : audit et export des données utilisateurs AD
  • Virtualisation VCenter : déploiement et gestion des VMs
  • Déploiement Linux (Debian 10) : serveur Apache intranet
Architecture résultante
  • Infrastructure redondante — aucun point de défaillance unique sur l'annuaire
  • Authentification unifiée — un compte AD pour le PC, le Wi-Fi et le RD Web
  • Visibilité totale via Grafana — alertes et métriques centralisées
  • Postes clients sécurisés par GPO — déploiement automatique à la connexion

Analyse réflexive :

💡
Ce que j'ai acquis. Réussir à coupler l'authentification Wi-Fi physique avec l'annuaire virtuel Active Directory a été ma plus grande fierté sur ce projet. Cela m'a fait comprendre la valeur d'une infrastructure centrée sur l'identité : un seul compte AD donne accès au PC, au Wi-Fi et au Remote Desktop Web.
⚡
Principale difficulté. La configuration du serveur NPS pour le 802.1x a été la partie la plus complexe : le débogage des échanges RADIUS entre le point d'accès et le contrôleur de domaine nécessitait de comprendre l'ensemble du flux EAP, sans documentation adaptée à notre environnement de TP.
🔄
Ce que je ferais différemment. J'aurais intégré Prometheus et Grafana dès le début du déploiement plutôt qu'en fin de projet. Avoir les métriques des serveurs en temps réel dès la phase de configuration aurait accéléré l'identification des problèmes de performance.
